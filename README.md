# VideoLab v1.0.0

**動画の再生・変換・計測・解析を、ローカルPCのブラウザから行うツールです。**

VideoLabは、Python / Streamlit / OpenCV / FFmpegを使用した動画計測アプリケーションです。AVIなどの産業用カメラ動画を扱い、動画の確認、再生速度変更、MP4保存、画像計測、輪郭解析、オプティカルフロー解析を行います。

このREADMEでは、現在の機能を **v1.0.0（初回正式版）** として説明します。機能追加の経緯はGitHubのPull Request履歴を参照してください。

> [!IMPORTANT]
> 映像の再エンコードやブラウザ再生は、画素値やフレーム位置に影響する可能性があります。**定量計測は原則として元動画・元画像を使い、変換MP4は再生・確認・共有用**として利用してください。

## 1. 主な機能

| タブ | できること |
| --- | --- |
| **その場で再生・コマ送り** | 動画再生、再生速度変更、フレーム移動、ブラウザ非対応動画のMP4変換 |
| **画像計測・画像処理** | 既知寸法による校正、距離・角度計測、輝度調整、二値化、輪郭抽出、画像重ね合わせ・差分 |
| **エッジ解析（Edge Counter）** | 静止画像・動画1フレームの輪郭抽出、ROI指定、輪郭統計、PNG/CSV/JSON出力 |
| **再生FPS変更・DL** | 任意区間の切り出し、FPS・倍率指定、CRF画質指定、高速シーク、MP4書き出し |
| **オプティカルフロー解析** | 手動・自動の特徴点選択、Lucas–Kanade追跡、軌跡動画と座標・速度CSV出力 |

- **入力動画**：MP4 / AVI / MOV / MKV / M4V（実際の読み込み可否はコーデックと実行環境に依存）
- **動画書き出し**：H.264 MP4
- **入力方法**：ブラウザからファイルを選択、またはStreamlitを起動しているPC上の絶対パスを指定
- **元ファイル**：変換・解析時に元動画や元画像を上書きしません
- **対象環境**：主にWindows 11上のローカル実行

## 2. インストールと起動

### 必要なもの

- Python **3.11以上**
- [uv](https://docs.astral.sh/uv/)（Python環境・依存パッケージ管理に使用）
- Windowsで利用できるWebブラウザ（Microsoft Edge / Google Chrome等）
- **ffprobe**：長尺動画の高速シークを利用する場合に必要

FFmpeg本体は通常、Python依存パッケージ `imageio-ffmpeg` 経由で使用します。ただし `ffprobe` は同梱されない環境があるため、別途インストールしてください。

Windowsでffprobeを導入する例：

```cmd
winget install --id Gyan.FFmpeg -e
```

インストール後は**ターミナルを開き直して**、次のコマンドで認識されることを確認します。

```cmd
ffprobe -version
```

ffprobeがない場合も動画変換自体は使用できますが、途中区間の高速シークは使わず、先頭からの逐次デコードに切り替わります。

### 起動手順

1. [GitHubリポジトリ](https://github.com/niiyaten/video-lab)の **Code → Download ZIP** から取得して展開するか、Gitでcloneします。
2. 展開先フォルダでPowerShellまたはコマンドプロンプトを開きます。
3. 以下を実行します。

```powershell
uv sync
uv run streamlit run app.py
```

4. ブラウザで **http://localhost:8501** を開きます。

Windowsでは、リポジトリ直下の `run.bat` から起動することもできます（uvのインストールが必要です）。

uvを使わずに起動したい場合：

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -e .
streamlit run app.py
```

## 3. 元動画を読み込む

画面上部の **「動画を読み込む」** で入力方法を選択します。

| 入力方法 | 用途 |
| --- | --- |
| **ファイル選択（ブラウザ）** | 比較的小さい動画を簡単に読み込む |
| **PC上のファイルパス（ローカル実行向け）** | 大容量AVIや長尺動画の読み込みに推奨 |

ファイルパス指定では、Streamlitを実行している**PC上の絶対パス**を入力してください。別のPCからWeb画面を閲覧している場合、そのPCのローカルパスを直接開く機能ではありません。

ブラウザアップロードの設定上限は **1,024 MiB** です。アップロードにはメモリと一時保存領域を使用するため、322,560フレームのような長尺動画では**ローカルパス指定**を推奨します。

読み込み後に表示されるFPS・フレーム数・再生時間は、主に動画メタデータから取得した値です。高速カメラでの**実際の撮影レート**とファイルの**再生FPS**が異なる場合、用途に応じて区別してください。

## 4. タブ別の使い方

### 4.1 その場で再生・コマ送り

動画の再生・停止、再生速度変更、フレーム番号ジャンプ、1枚／10枚送り、先頭・末尾移動などができます。プレーヤーの主なキー操作は次のとおりです。

| 操作 | キー |
| --- | --- |
| 再生／停止 | Space |
| ±1フレーム | ← / → |
| ±10フレーム | Shift + ← / → |
| 先頭／末尾 | Home / End |

操作前にプレーヤーをクリックしてください。これらは**ブラウザの時刻シークに基づく操作**であり、圧縮動画の厳密な1フレーム単位の表示を保証するものではありません。

#### AVIをブラウザ再生用MP4にする

AVIなどブラウザで再生しにくい形式は、**「AVI・独自コーデック向け：ブラウザ再生用MP4を作る」** を開いて変換します。

1. 変換フレーム数を指定します（**0で全フレーム**）。
2. H.264の画質（CRF）を指定します（初期値23）。
3. **「互換MP4を作成してプレーヤーで開く」** を押します。

原則として、元動画の**再生FPSとフレーム数を維持**してMP4にします。ここで再生速度を変えるのではなく、形式をブラウザ互換にする機能です。音声がある場合は対応するストリームをAACへ変換します。

生成した互換MP4の「プレビューMP4を保存」ボタンはファイル全体をブラウザ用に読み込むため、大容量動画ではメモリ使用量に注意してください。

### 4.2 画像計測・画像処理

「画像計測・画像処理」タブでは、ブラウザ上の画像ツールを使用します。

- 既知長さの2点を選んでスケールを校正
- 点間距離・角度の計測
- コントラスト／明るさの調整、二値化、輪郭表示
- 2枚の画像の重ね合わせと差分表示

校正した距離は選択点や画像の品質に依存します。実寸計測では、対象面と校正面、レンズひずみ、カメラの姿勢、画素スケールを確認してください。

### 4.3 エッジ解析（Edge Counter）

静止画像（PNG / JPEG / BMP / TIFF / WebP）、PC上の画像ファイル、または読み込んだ動画の**1フレーム**を解析できます。

基本的な処理の流れ：

1. 画像と、必要に応じてROI（数値指定／画像の2点クリック）を選択する。
2. `α`（コントラスト）・`β`（明るさ）とGaussian／Medianぼかしを設定する。
3. 二値化（Binary）またはCannyで輪郭入力を作る。
4. 必要に応じてOpen / Close / Dilate / Erodeと面積フィルタを設定する。
5. 全輪郭／最大輪郭／上位N輪郭、および点列出力方式を選ぶ。
6. 輪郭重畳画像、マスク、輪郭統計、点列、解析条件を出力する。

主な出力は **PNG / CSV / JSON** です。点列の座標原点は画像左上で、Xは右向き、Yは下向きです。輪郭面積はOpenCVによる幾何学的面積であり、残った輪郭線の画素数とは異なります。

**動画全フレームのEdge Counter一括解析には対応していません。**

### 4.4 再生FPS変更・DL

選択区間の**全フレームを保持したまま、出力動画の再生速度を変える**機能です。AVIを入力しても、出力はMP4になります。

#### FPSと倍率の指定

**「出力再生FPS」と「再生速度（倍率）」は連動**します。どちらを変更してももう一方が更新され、ラジオボタンによる切り替えは不要です。

```text
出力FPS = 元動画の再生FPS × 再生倍率
再生倍率 = 出力FPS ÷ 元動画の再生FPS
```

元動画が120 FPSの場合：

| 指定 | 出力FPS | 再生時間 |
| --- | ---: | --- |
| 1倍速 | 120 | 元の動画と同じ |
| 0.5倍速 | 60 | 2倍の長さ |
| 0.25倍速 | 30 | 4倍の長さ |
| 2倍速 | 240 | 半分の長さ |

これは**フレームの間引き・補間ではありません**。画面で指定した区間のフレームを残し、再生のタイミングを変更します。**音声は出力しません。**

#### 区間の指定

- **フレーム番号**：0始まり、開始・終了番号の**両端を含む**。例：300000〜300999は1,000フレーム。
- **動画の秒数**：開始を含み終了を含まない区間。固定FPS動画を想定し、フレーム境界に換算します。
- 必要なら「開始・終了フレームの画像を確認」で切り出し位置を確認します。

#### 画質とエンコード速度

再エンコードが必要な場合、H.264のCRFとエンコード速度（ultrafast / veryfast / medium）を指定できます。CRFの初期値は23です。

| CRFの目安 | 用途 |
| --- | --- |
| 18 | 高画質・大容量 |
| **23（初期値）** | 標準 |
| 28 | 容量優先 |

CRFの設定可能範囲は0〜51で、**値が小さいほど高画質・大容量**です。CRF 0でも、`yuv420p`への色形式変換等により元動画と画素値が一致するとは限りません。

元動画がH.264で**全区間**を書き出す場合、再圧縮なし（stream copy）を自動試行します。成功すれば映像の圧縮データをそのまま保持するため、**CRFは適用されません**。一部区間やMJPEG AVI等では通常、H.264へ再エンコードします。

#### 高速シークと正確性の検証

途中から切り出す場合、`ffprobe`でフレームの表示時刻（PTS）とキーフレームを調べ、開始位置の直前のキーフレーム付近から処理します。高速シークが適用できる動画では、先頭から全フレームをデコードする時間を省けます。

高速シーク後は**先頭・末尾のPTS、出力フレーム数、FPS**を検証します。索引が信頼できない場合や検証に失敗した場合は、生成途中のMP4を破棄し、先頭からの逐次デコードへ自動的に切り替えます。特殊コーデックやVFR動画では高速化が適用されない場合があります。

#### MP4の保存

1. **「選択区間のFPSを変更してMP4を作成」** を押す。
2. 完了後、生成ファイルの処理方式・FPS・フレーム数・容量を確認する。
3. 次のいずれかで保存する。

| 保存方法 | 対象 |
| --- | --- |
| **ブラウザからMP4をダウンロード** | 出力が128 MiB以下の場合 |
| **指定したPCのパスに保存** | 大容量動画にも対応。Streamlitを実行しているPCの絶対パスに保存 |

PC上のパスへ保存する場合は**既存ファイルを上書きしません**。保存処理の進捗も表示します。元動画は変更しません。

### 4.5 オプティカルフロー解析

OpenCVの**疎なLucas–Kanade法（Pyramidal LK）**で画像内の点を追跡し、追跡結果を可視化MP4とCSVで出力します。

1. 「オプティカルフロー解析」を開く。
2. 「手動で選択」（初期値）または「画面全体から自動検出」を選ぶ。
3. 必要なら、追跡開始フレームとROIを指定する。
4. 手動モードでは画像をクリックして追跡点を登録する。
5. 追跡条件（軌跡長、特徴点間隔など）を設定し、解析を実行する。

手動モードの「クリック付近の特徴点へ自動補正」と「追跡中に新しい点を自動追加」は**初期状態OFF**です。前者をONにするとShi–Tomasi特徴点へ寄せる場合があります。後者をONにすると追跡中に新しいIDの点を追加します。

結果動画の**再生FPS**は指定できますが、CSVの時刻・速度は**元動画のメタデータFPS**を使って計算されます。フレーム番号も元動画先頭からの番号です。

CSVの主な列：

| 列名 | 内容 |
| --- | --- |
| `frame` | 元動画内のフレーム番号（0始まり） |
| `time_s` | 元動画先頭からの時刻（秒） |
| `point_id` | 追跡点ID（再利用しない） |
| `x_px`, `y_px` | 画像左上原点の座標（px） |
| `dx_px`, `dy_px` | 前フレームからの変位（px） |
| `speed_px_s` | 変位に元動画FPSを掛けた速度（px/s） |
| `status` | 1：追跡中、0：追跡喪失 |

CSVはExcel等で扱いやすいUTF-8（BOM付き）です。追跡開始時には変位・速度の値がありません。追跡喪失後の同じIDを自動で復活させる機能や、mm/sへの自動変換はありません。

## 5. 計測・運用上の注意

- **再圧縮と画素値**：H.264 MP4への再エンコードは通常、画素値を変えます。エッジ・輝度・微小変位などの解析には元動画を使用してください。
- **再生FPSと撮影FPS**：メタデータのFPSが実際の撮影レートと一致しない動画では、計測時間・速度の解釈に注意してください。
- **VFR／特殊コーデック**：可変フレームレート動画、メーカー独自のAVI、破損したフレーム時刻では、フレーム境界や変換結果の検証が必要です。
- **ブラウザのコマ送り**：GOPやシーク精度の制約により、表示上の厳密なフレーム選択は保証されません。
- **画像計測**：校正値の妥当性、レンズひずみ、射影、撮影時のブレを別途確認してください。
- **長尺動画**：十分な空きディスク容量を確保してください。処理時間や推定残り時間は圧縮方式・解像度・ストレージ速度に依存します。
- **ローカル運用**：ローカル起動時の処理はそのPCのPythonプロセスで実行します。外部ネットワークに公開する場合はアクセス制御を別途設定してください。

## 6. 開発・テスト

アプリの画面は`app.py`、処理エンジンは`videolab/`、ブラウザ側の画像・動画UIは`assets/`、テストは`tests/`に置いています。

```text
video-lab/
├─ app.py                  # Streamlitアプリ
├─ assets/
│  ├─ frame_player.html    # 動画プレーヤー
│  └─ image_lab.html       # 画像計測UI
├─ videolab/
│  ├─ preview.py           # AVI等を再生用MP4へ変換
│  ├─ fps_fast.py          # FFmpegによるFPS変更・書き出し
│  ├─ fps_seek.py          # キーフレーム高速シーク・境界検証
│  ├─ encoding.py          # CRF設定
│  ├─ playback_speed.py    # FPSと倍率の相互変換
│  ├─ edge_counter.py      # エッジ解析エンジン
│  ├─ edge_ui.py           # エッジ解析UI
│  ├─ optical_flow.py      # LKオプティカルフロー
│  ├─ image_processing.py  # 画像処理
│  └─ video_io.py          # 動画入出力
├─ tests/                  # 自動テスト
├─ pyproject.toml
└─ run.bat
```

テストの実行：

```powershell
uv run pytest -q
```

GitHub Actionsでの実行状況は、リポジトリの **Actions** タブを確認してください。全コーデック・全カメラ形式での動作は保証しません。
